Variations on the same path

  • Scout. Spawned with --scout; step 11 becomes writing data/<id>/report.md. Teardown needs that report and the captain-call gate instead of landed work. If a fix is then authorized, fm-promote.sh turns the same worker into a ship between steps 12 and 13.
  • no-mistakes. The worker drives the pipeline and reports done … PR <url> checks green only after CI is green, and fm-crew-state.sh reads the run-step as authoritative AGENTS.md:387-394.
  • local-only. No push or PR; the worker stops on a clean branch, and teardown requires the branch to be merged into local main through bin/fm-merge-local.sh bin/fm-teardown.sh:1808-1825.
  • A stuck or dead worker. fm-control.sh relaunch --note … replaces the agent in the same worktree; on Herdr a destroyed pane can be reclaimed.
  • Routed to a secondmate. The whole path runs inside the secondmate's home, against its own backlog; its reply returns through its status log AGENTS.md:297-299.
