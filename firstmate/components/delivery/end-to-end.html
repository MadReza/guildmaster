Delivery end to end

One realistic path traced through every delivery component: a product-facing fix on a GitHub project registered no-mistakes-prod-only, yolo off, with one ask-user finding on the way, followed by how the direct-PR, local-only, yolo-on, and away variants differ.

How the other paths differ

VariantWhat changes
direct-PR (for example, internal tooling on the same prod-only project)Steps 4 to 8 disappear. The worker pushes fm/<id>, opens a non-draft PR with gh-axi, and reports done: PR <url> with no checks green bin/fm-dod-lib.sh:250-262. The merge gate still demands every check green at head, so CI is proved at step 12 instead of by the pipeline.
local-onlyNo PR, poll, or forge. The worker reports done: ready in branch fm/<id>; on approval the supervisor runs bin/fm-merge-local.sh <id>; teardown accepts the local default branch as landed and skips the clone refresh (Local landing).
yolo onStep 11 becomes a one-line after-the-fact report: firstmate merges green, in-scope work itself and gives "a one-line full-URL … outcome" AGENTS.md:358 AGENTS.md:364. A red check, a destructive or security-sensitive change, or an ask-user finding that expands the contract still goes to the captain.
Captain awayThe Pi supervision branch handles wakes. It may merge only what the captain's recorded away words call for, and only green; the merge is recorded as away; --allow-red, --auto, and queued merges are refused; a local-only landing waits for the captain's return; landed workers are still torn down bin/fm-branch-prompt.sh:104-114 bin/fm-branch-prompt.sh:63-67.
Secondmate homeThe same steps run inside the secondmate's own home. fm-pr-check.sh publishes done [key=child-pr-<id>]: child <id> PR ready: <url> mode=… yolo=… to the parent channel, and the merge outcome goes upward as done [key=merged-<id>]: merged <id> <url> bin/fm-pr-check.sh:185-191 bin/fm-merge-outcome-lib.sh:79-80.
Pipeline withdrawnResolve the task direct-PR at intake; nothing else in steps 9 to 14 depends on no-mistakes (Where the code assumes the tool).
