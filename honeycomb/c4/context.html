System context

Honeycomb as one box: who uses it, what sends it data, what it notifies, and what it runs on. The next level, Containers, opens the box.

Read on 2026-10-02 from Honeycomb's docs and public repositories. Every node carries a provenance badge: D documented, S stated in a talk or blog, I inferred.

The system in scope

Honeycomb is a hosted service with two public regions, reached at api.honeycomb.io in the US and api.eu1.honeycomb.io in the EU, each accepting OTLP over gRPC, HTTP/protobuf and HTTP/JSON with the API key in an x-honeycomb-team header documented docs-otel. The EU region opened in January 2024 for data residency pr-eu. The web app is ui.honeycomb.io talk/blog devops-2017, and agents reach the hosted MCP server at mcp.honeycomb.io/mcp or mcp.eu1.honeycomb.io/mcp docs-mcp-config.

A customer's account is a team, which holds environments, which hold datasets of events. "Honeycomb queries run within a single environment by design", and the ingest key decides which environment receives the data docs-resource-structure. The data model page covers this.

Since 2025-11-19 the same system can also run as Honeycomb Private Cloud, which "runs Honeycomb in your cloud account instead of on Honeycomb's infrastructure" and "uses the same architecture and codebase as Honeycomb SaaS" documented docs-private-cloud. It is self-managed or Honeycomb-managed, on AWS only, and its architecture page lists EC2, EKS, ECS, Lambda, S3, RDS, ElastiCache and Bedrock docs-pc-arch. That list is the only public inventory of the services Honeycomb itself runs on.

Retired or deliberately outside the box

  • Beelines, Honeycomb's first tracing SDKs, reached end of life on 2025-08-12 docs-migrate-beelines. Its OpenTelemetry distributions for Java, .NET, Python, Node.js and Go are archived; only the web SDK remains docs-migrate-distros repo-hny-otel-web.
  • The self-hosted MCP server (honeycombio/honeycomb-mcp) was Enterprise-only, ran locally over stdio, and is deprecated and archived in favour of the hosted server repo-honeycomb-mcp.
  • Secure Tenancy, an on-premises proxy that held the customer's encryption keys so "Honeycomb never has access to the data", was patented in 2020; its Helm chart was marked deprecated and removed in May 2023 blog-secure-tenancy helm-secure-tenancy.
  • The Honeycomb Kubernetes Agent is in maintenance and the Network Agent is archived; Kubernetes users are steered to OpenTelemetry docs-k8s-agent repo-network-agent docs-k8s.
  • Query Assistant (2023), the first natural-language query feature, is gone from the docs; Canvas took its place inferred from its old URL redirecting to "Build a query" pr-query-assistant.
