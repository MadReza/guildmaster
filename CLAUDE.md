# Guildmaster

This file is guidance for agents that change Guildmaster, not the Guildmaster's charter: a session at the patron's front desk takes its role from the start-up hook (`.claude/settings.json`), which gives it the charter.

- `TERMINOLOGY.md` owns the project vocabulary; read it before writing Guildmaster material.
- `firstmate/` is a static research site documenting Firstmate as it is, not Guildmaster's design. Read `firstmate/AUTHORING.md` before adding or changing any page there: it owns the page template, the shared-file append-only rule, navigation registration in `firstmate/assets/nav-data.js`, the diagram classes, and the evidence standard.
